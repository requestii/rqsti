# Requestii

Production-ready marketplace platform blueprint and starter implementation for Tanzania/Africa.

## Monorepo Structure
- `backend/` FastAPI + SQLAlchemy backend
- `mobile/` Flutter starter architecture (Riverpod + GoRouter)
- `infra/` Docker, compose, CI/CD, deployment docs
- `docs/` architecture, roadmap, ERD, API docs

## Quick Start
```bash
docker compose -f infra/docker-compose.yml up --build
```
